# ARCHIVE
Устаревшие документы и записи.
Ничего не удаляется (I6): устаревшее перемещается сюда с указанием даты и причины.

## Правила
- Имя файла сохраняется, при необходимости добавляется суффикс с датой: `NAME.YYYY-MM-DD.md`.
- В начало перемещённого файла добавляется блок:
  - **Причина архивации:**
  - **Дата архивации:**
  - **Заменяющий документ (если есть):**
- ARCHIVE не является источником истины (I1).
