# INVARIANTS.md
Правила, которые нельзя нарушать.

## I1. Источник истины
Для каждого вида состояния существует один явный источник истины.
- Статус проекта → CURRENT_STATE.md
- Решения → DECISIONS.md (accepted)
- Происхождение утверждений → PROVENANCE.md
- Архитектура → docs/ARCHITECTURE.md (если существует)
- Метод → docs/METHOD.md (если существует)

Документация определяет систему. Документация сама по себе не является доказательством фактического исполнения.

## I2. Состояния знания
Запрещены автоматические переходы:
- OBSERVATION → FACT / VERIFIED
- HYPOTHESIS → FACT / VERIFIED
- UNKNOWN → любое заполненное утверждение без основания

Любой переход статуса требует явного основания и фиксации (см. meta/transitions.md или PROVENANCE + DECISIONS).

## I3. Append-only для первичных данных
Первичные записи (records/, trace, полевые логи, исходные материалы) не перезаписываются.
Исправления только через новую запись с указанием причины.

## I4. Provenance
Значимые утверждения уровня FACT, VERIFIED и RESULT должны иметь прослеживаемое происхождение в PROVENANCE.md или эквивалентной записи.

## I5. Изменение инвариантов
Изменение любого правила этого файла допускается только через запись в DECISIONS.md со статусом accepted.

**Исключение (инициализация):** при первом создании проекта допускается запись D-000000-00 с пометкой «initial setup» без требования предыдущего accepted decision.

## I6. Удаление
Документы и записи не удаляются. Устаревшее перемещается в ARCHIVE/ с указанием даты и причины.

## I7. Проверяемость состояния
Нормативные документы определяют требуемое поведение, но не считаются доказательством фактического исполнения.
Значимые утверждения о состоянии системы должны иметь проверяемое основание.
Дата обновления документа не заменяет дату и результат проверки.

## I8. Синхронизация
После фиксации решения в DECISIONS.md со статусом accepted в разумный срок (рекомендуется в рамках той же сессии или не позднее 24 часов) должен быть обновлён CURRENT_STATE.md либо создана запись о причине, по которой обновление невозможно.
