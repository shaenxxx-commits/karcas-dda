# docs/KNOWLEDGE_STATES.md
Модель состояний знания (двумерная).

## Эпистемический статус
- **UNKNOWN** — явно обозначенный пробел. Не заполняется предположениями.
- **HYPOTHESIS** — проверяемое объяснение. Требует процедуры проверки.
- **SUPPORTED** — имеет подтверждающие данные, но ещё не прошло полную верификацию.
- **VERIFIED** — подтверждено установленной процедурой или источником.

## Тип утверждения
- **OBSERVATION** — непосредственно зафиксированное наблюдение.
- **RESULT** — результат выполненной процедуры (эксперимент, измерение, действие).
- **INTERPRETATION** — объяснение значения наблюдения или результата.

## Правила
- Одно утверждение может иметь и эпистемический статус, и тип.
- Переход эпистемического статуса фиксируется (meta/transitions.md или через PROVENANCE + DECISIONS).
- INTERPRETATION никогда не становится VERIFIED автоматически только потому, что красиво сформулирована.
- RESULT не является автоматически VERIFIED.
